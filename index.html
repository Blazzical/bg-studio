Vector shapes

Pen tool (P): click to drop anchor points, click-drag to pull out a curve. Click the first point to close. Esc/Enter finishes · Backspace removes the last point.

Magic wand

No selection — click a colour in the image.
Click a colour to select the pixels like it. Shift-click adds · Alt-click subtracts · W toggles · Esc deselects. While a selection is live the Brush (paint and erase) only touches pixels inside it.

Brush

Brush applies to the selected image / paint layer. Erase = manually rub out the background. [ / ] resize · B toggles. With a magic wand selection live, strokes are clipped to it.

Selected layer

Click a layer on the canvas to select it.
Tip: select text in the box, then use B/I/U, size, colour, outline or a font — it styles just that part.
Swatches
Click a swatch to apply to the last-touched colour · shift-click removes it. “Save” stores this text’s full style; “Default” = new text starts from it.
Click a cell to select · Shift-click another for a range.
